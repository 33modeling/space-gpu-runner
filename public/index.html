👑 Admin Run-Approval (/run-approval) & TaskOrbit 승인 대기열

📌 Admin 권한으로 워크로드가 제출되면 /taskorbit/api/v1/approvals에 pending 항목이 생성됩니다. 서버의 Admin 자동 승인 루프(기본 5초 간격 + 생성 직후 2초×8회 고속 추적)가 감지 즉시 POST /taskorbit/api/v1/approvals/{id}/approve?groupId={groupId}를 호출하여 승인하므로 멈추지 않고 바로 GPU가 할당됩니다.
구분 / Approval ID Run ID / 워크로드명 사용자 / Namespace 요청 리소스 (GPU/CPU/MEM) TaskOrbit 단계 / 상태 Admin 제어 (Approve / Reject)
잠금 해제 후 자동으로 승인 대기 목록을 불러옵니다.
